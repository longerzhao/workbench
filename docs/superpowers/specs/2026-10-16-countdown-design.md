# 倒计时 / 正计时 · 设计规格

> 日期：2026-10-16 · 状态：已实现

## 1. 目标

侧栏「番茄」旁增加 **计时** 页（`/#/countdown`）。内置中国法定假期的下一次开始日倒计时，并允许自定义倒计时与正计时。总览放一张最近倒计时卡片。

**范围内**

1. 内置：元旦、春节、清明、劳动节、端午节、中秋节、国庆节（只取假期开始日，不含调休）
2. 自定义：标题、日期、颜色；可编辑、可删除
3. 倒计时过期后显示「已过去」，不自动删除；正计时持续累加
4. 每秒刷新（天 / 时 / 分 / 秒），按当天 0 点起算
5. 假期可隐藏（存在 meta），不可删除
6. 总览卡片展示最近一个未过期倒计时，并链到计时页
7. 自定义计时纳入备份

**范围外**

- 推送提醒、重复规则、调休日历
- 把假期写入日历日程

## 2. 数据

假期日期不入库，由 `lunar-javascript` 按公历年计算（春节 / 端午 / 中秋走农历，清明走节气，元旦 / 劳动节 / 国庆为公历固定日）。

自定义条目在 Dexie v3 表 `countdowns`：`id, title, mode ('down' | 'up'), date, color, order`。隐藏的假期 id 存在 meta `countdown.hiddenHolidays`。

## 3. 排序

即将到来的倒计时在前（越近越靠前），已过期的倒计时其次，正计时按已过天数从多到少。

## 4. 界面

- 计时页分「法定假期」「倒计时」「正计时」；隐藏的假期离开主列表，收在页底「已隐藏 N 个假期」里，点「恢复」才回到列表
- 总览卡片默认 `colSpan: 4`，已有布局会把它补到末尾
