# P3 Todos Page Implementation Plan

> **For agentic workers:** Execute task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the `/#/todos` placeholder with a full dual-pane todo manager (views, projects, subtasks, drag reorder, batch ops, trash UI).

**Architecture:** Feature slice under `src/features/todos/`; URL query (`view`, `project`) drives list scope; `todoRepo.listByFilter` is the single query entry; secondary filters / expand / multi-select stay in React state.

**Tech Stack:** React 19, react-router 7 (hash search params), Dexie + useLiveQuery, @dnd-kit, existing UI primitives.

## Global Constraints

- No direct `import { db }` from features/components (repos only).
- No schema migration; archive = soft-delete to trash.
- `today` view must match `todoRepo.listToday` semantics.
- No git commits unless user asks (repo may be uninitialized).
